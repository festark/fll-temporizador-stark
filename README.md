# FLL Timer - Temporizador de Avaliação [2.0.0] - 2025-11-17

### Adicionado
- Sonorização nos tempos iniciais e finais (1 minuto)
- Suporte para troca de idioma na interface (PT-EN)

### Melhorado
- Cores na barra de progresso agora estão coerentes com a sonorização

Temporizador para **salas de avaliação do FIRST LEGO League (FLL)**.

## Funcionalidades
- Contagem regressiva por fase
- Botões: **Iniciar / Pausar / Continuar / Anterior / Próxima**
- Barra de progresso **arrastável**
- Logo oficial do FLL
- Som de alerta
- Botão **X** para fechar com segurança


## Fases (tempo oficial)
1. Projeto de Inovação → 5 min  
2. Feedback Inovação → 5 min  
3. Design do Robô → 5 min  
4. Feedback Robô → 5 min  
5. Perguntas e Respostas → 8 min  
6. Deliberação dos Juízes → 10 min

## Como usar
1. Execute `fll_temporizador.py` com Python
2. Digite o nome da equipe
3. Use os botões para controlar
